# DUstatus

Minimal Android download/upload speed overlay experiment for Android 15 / HyperOS.

**Limitation:** Android blocks ordinary app overlays from drawing inside the protected system status bar. DUstatus positions its indicator immediately below the status bar where permitted; it cannot guarantee placement next to the clock without system privileges.

Open in Android Studio or run the GitHub Actions Android APK workflow. Grant overlay and notification permissions, then press Start.
